Optional final step. Reads the offchain asset location ledger and publishes a fresh store-inventory.json to agroverse-inventory. This JSON is what agroverse.shop reads to show in-stock products. Skip this if you only need the ledger updated but don't need the storefront refreshed yet (e.g. batching multiple settlements).
