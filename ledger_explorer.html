Ledger Explorer

The DAO's public, auditable RSA-attestation ledger — one immutable JSON file per signed event. Search by transaction id or message id, read the signed record, and independently re-verify it offline with openssl.

A raw transaction id (the base64 signature) is accepted too — it is SHA-256 hashed to its canonical filename. Message ids look like 171 or Edgar_20260924125541_071.
